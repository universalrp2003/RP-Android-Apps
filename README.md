# RP-Android-Apps (RP Ideas) — Official Open-Source Tamil & English Android Apps

Official repository (**`universalrp2003/RP-Android-Apps`**) and download hub (**[universalrp2003.github.io/RP-Android-Apps](https://universalrp2003.github.io/RP-Android-Apps/)**) for ten open-source Android apps in **தமிழ் (Tamil)** and **English**: seven actively maintained utilities (**SMS Guard / குறுஞ்செய்தி காவலன்**, **Live Guard / CleanSweep**, **Ramesh Radio / ரமேஷ் ரேடியோ**, **PulseEQ**, **RP Vocal Remover Studio**, **Oor Arivippu / ஊர் அறிவிப்பு**, **Vasanthi AI / வசந்தி AI**) plus **Secret Message**, a separately published app that is not independently security-reviewed. Developed by **Rameshprathap R (`@universalrp2003`)** with shared project contributions, including software assistance from **Arena.ai Agent Mode**. **Secret Message is published but is not independently security-reviewed.** No outside security expert has reviewed it, and the mls-rs library has not had a full third-party audit, so do not rely on it where your safety depends on secrecy. The relay sees both phones' IP addresses, when they connect and how much data they send, and the start of each session before the safety-code check; it cannot read messages, drawings or pictures. See [`secretmessage/releases/secret-message-v1.1.3.md`](secretmessage/releases/secret-message-v1.1.3.md) and [`docs/secret-message-security-design.md`](docs/secret-message-security-design.md).

## Privacy and audio

- SMS Guard processes SMS locally on-device as your chosen default SMS app, never speaks OTPs aloud, locks bank/card/UPI/FASTag statements behind biometrics, and uses optional NextDNS-compatible online neural voice readout with automatic offline system TTS fallback. See [`PRIVACY.md`](PRIVACY.md).
- Live Guard stores its local settings and optional histories on-device. Optional AI, web, hash, weather, and neural voice tools contact the selected services only when used; see [`PRIVACY.md`](PRIVACY.md).
- Ramesh Radio contacts the selected station to stream and searches the public station directory only when requested. Local songs stay on the device.
- PulseEQ processes audio locally. Its optional update check contacts GitHub; system-wide effects remain device/ROM-dependent.
- RP Vocal Remover Studio downloads its checksum-pinned model from the upstream GitHub release. Selected songs are processed on-device; the app has no selected-audio upload path. The first output is a WAV, the optional second pass is user-started, and MP3 export is lossy while the WAV is retained.
- Oor Arivippu uses location and Android's Geocoder for trip announcements and destination lookup, plus optional Studio Ultra-HD online neural voice synthesis with instant offline system TTS fallback. Settings and the selected destination are stored locally; see [`PRIVACY.md`](PRIVACY.md).

The developer does not operate an app backend, ad network or analytics service. Third-party services may receive requests when an online feature is used or enabled and during update checks, under their own policies; see the privacy policy for details.

The project uses JDK 17, Gradle 8.14.3, the Android SDK and NDK. Open the repository root in Android Studio or use the wrapper:

```sh
./gradlew :smsguard:testReleaseUnitTest :smsguard:lintRelease :smsguard:assembleRelease

./gradlew :cleaner:testDebugUnitTest :cleaner:testReleaseUnitTest \
  :radio:testDebugUnitTest :radio:testReleaseUnitTest \
  :equalizer:testDebugUnitTest :equalizer:testReleaseUnitTest \
  :vocalremover:testDebugUnitTest :vocalremover:testReleaseUnitTest

./gradlew :cleaner:assembleRelease :radio:assembleRelease \
  :equalizer:assembleRelease :vocalremover:assembleRelease

./gradlew :oorarivippu:testReleaseUnitTest :oorarivippu:lintRelease :oorarivippu:assembleRelease
```

For the **non-shipping Secret Message preview only**, run `./gradlew :secretmessage:testDebugUnitTest :secretmessage:lintDebug :secretmessage:assembleDebug`; this produces a debug preview, not a release APK. GitHub Actions builds the four legacy batch apps and performs the required localization, regression, package/version/signature and release-asset checks. SMS Guard, Oor Arivippu, and Secret Message (`secretmessage/wifi-test`) each have their own standalone test and marker-gated stable release workflows. The preview is excluded from every release and bundle task and has its own test-only workflow (`secret-message-preview.yml`): contract test, unit tests, lint, debug APK, a merged-permission allowlist, and a hosted API 35 emulator UI smoke test. All of these passed in [run 38835582621](https://github.com/universalrp2003/InternetRadio/actions/runs/38835582621); that is not a physical-device test. The four-app batch workflow generates Play bundles for CleanSweep, Ramesh Radio and PulseEQ; SMS Guard, RP Vocal Remover Studio, Oor Arivippu, and Secret Message are distributed as standalone signed APKs.

## Project scope and repository URLs

There are ten published RP Ideas Android applications in this repository: seven actively maintained utilities (**SMS Guard / குறுஞ்செய்தி காவலன்**, **Live Guard / CleanSweep**, **Ramesh Radio / ரமேஷ் ரேடியோ**, **PulseEQ**, **RP Vocal Remover Studio**, **Oor Arivippu / ஊர் அறிவிப்பு**, **Vasanthi AI / வசந்தி AI**) plus the separately published **Secret Message / இரகசிய செய்தி** (`1.1.3`), which has not been independently security-reviewed. The local-only `:secretmessage` development preview is separate from the published `secretmessage/wifi-test` app. Earlier app modules were retired from the active source tree; their already-published GitHub Releases and tags are retained as historical records and are not built by current CI.

`RP-Android-Apps` is the primary updater source and `InternetRadio` is the verified fallback. The four legacy bridge clients check the new repository first and keep the old endpoint during the agreed migration grace period that began 14 October 2026; do not archive or rename `InternetRadio` until the migration checks are complete. On 18 October 2026 the owner decided to move the source and future development to `RP-Android-Apps`, keeping `InternetRadio` as the update backup; see [`docs/source-migration.md`](docs/source-migration.md). Oor Arivippu 1.0.0 and 1.0.1 were published to both repositories separately and are not part of that four-app bridge batch. See [`docs/repository-migration.md`](docs/repository-migration.md).
