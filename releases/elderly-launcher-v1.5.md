# Elderly Launcher 1.5 — fresh-install signing migration

**Version:** 1.5 · **versionCode:** 6 · **Package:** unchanged.

This release keeps Elderly Launcher 1.4's readable controls and browser-only update handoff. The Android signing identity changes because the former signing key was exposed; no app behavior or permission change is intended.

**Install warning:** Android cannot update an old-key installation with this APK. Download this official APK first, export/back up anything important, then uninstall the old launcher and install this version through Android. Uninstalling may erase local data and launcher settings. Do not uninstall before obtaining the replacement APK. Stop if Play Protect warns; do not bypass it.

The owner tested the previous 1.4 artifact, not this fresh-key 1.5 APK. This exact replacement-key APK was not installed on a phone. CI verification is not a device test or Play Protect clearance. The previous 1.4 tag and asset remain unchanged.
