# SMS Guard 1.1.9

## Changes

- Optional OTP sender-only voice announcements; OTP digits are never spoken. Sender labels do not prove authenticity.
- Visible inbox loading progress for large histories, including more than 1,000 messages; history is not silently capped.
- Reduced OEM cursor pressure with defensive cursor access and safe diagnostics on inbox failures.

## Device test

No physical-device test of this exact build. The friend's Redmi/MIUI inbox refresh error is NOT confirmed fixed. Older-device behavior, large-inbox refresh, and sender-only announcements require device validation. No promise of failure-free operation is made. No new permissions are requested by these changes.
