# Live Guard 2.76 — reliable eight-headline news voice

**Version:** 2.76 · **versionCode:** 81 · **Package:** unchanged.

This repair keeps the requested eight-headline news bulletin and the 30m / 1h / 2h / 3h announcer intervals. Long bulletins are now spoken as several short HD clips instead of one oversized request, so the eighth headline is not silently cut off by the shared voice engine's text limit. The manual **Read today's news** button and each headline's **Read aloud** action now use the news voice path, clear stale queued announcements, and report honestly when the HD voice cannot finish. A failed or stopped read no longer marks headlines as already announced, so the next interval can retry them.

No new Android permissions are declared. The exact 2.76 candidate APK was not installed on a phone; CI compilation and regression tests are not a device test, Play Protect clearance, or all-device certification.

**Install warning:** Version 2.76 uses the same replacement signing identity as 2.75 and 2.74, so it can update those installations normally. Android cannot update installations signed with the exposed pre-2.74 key. If you are on an older version, download this official APK first, export or back up anything important, then uninstall the old app and install this APK through Android. Uninstalling may erase local data. Do not uninstall before obtaining the replacement APK. Stop if Play Protect warns; do not bypass it.
