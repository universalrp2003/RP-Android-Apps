# Tamilan Store0.8 / code8 — galleries and a calmer storefront

Owner authorized screenshot refresh, visual improvements, scrolling text, build/publication and website verification on1 November2026.

- Refreshed teal/blue storefront with Tamil/English RP Ideas welcome text and actual catalog count. Gentle text scrolling only: no flashes, strobe, autoplay audio, adverts or extra network feed.
- Pause/enable control is saved locally. Scrolling is disabled while the app is not resumed, when Android animations are disabled, or while touch exploration is active. Static text wraps instead of hiding the message; full text remains available to accessibility services. Existing search, filters, update checks, verification, cancellation, user-confirmed Android installer and no-downgrade protections remain intact.
- All13 ordinary apps now have bundled real screenshot galleries: seven new empty-record/blank-form DailyVault screens fetched from the owner's Drive folder, and six privacy-reviewed SMS Guard screens. No inbox/message preview, account fragment, spending summary or backup password from the newly supplied raw screenshots is included. Older galleries remain labelled as earlier screens. Settings shown are owner selections, not defaults or security certification.
- Website image refresh includes SMS Guard, DailyVault and Tamilan Store itself; embedded private thumbnails in the Store website images are explicitly masked. Other existing Store app screens can be reused on website rather than generic illustrations; no unrelated APK is rebuilt for publication.
- Same package `com.universalrp.tamilanstore`, established signing identity, minAPI26 and normal in-place update from0.7. Uninstalling may erase local data; do not uninstall a same-key installation. No permission expansion, uninstall/data-reset, silent installation or Google-approval claim. Existing published Store0.7 and other release assets stay immutable.

தமிழன் அங்காடிக்கு புதிய நிற அமைப்பும் தமிழ்/ஆங்கில வரவேற்பும் மெதுவாக நகரும் உரையும் சேர்க்கப்பட்டுள்ளன. மின்னல்/வேக ஒளி மாற்றம் இல்லை. உரை நகர்வை நிறுத்தலாம்; தேர்வு சேமிக்கப்படும். Android இயக்கங்கள் நிறுத்தப்பட்டாலோ திரை வாசிப்பு தொடு ஆய்வு செயலிலிருந்தாலோ செயலி பின்னணியில் இருந்தாலோ உரை நகராது. முழு உரையும் படிக்கக் கிடைக்கும்.

தினக்கணக்குக்கு ஏழு காலிப் பதிவு/படிவத் திரைகளும் SMS Guard-க்கு ஆறு தனியுரிமை சரிபார்த்த திரைகளும் சேர்க்கப்பட்டுள்ளன. தனிப்பட்ட செய்திகள், கணக்கு விவரங்கள், செலவுச் சுருக்கம் அல்லது காப்புக் கடவுச்சொல் சேர்க்கப்படவில்லை. பதின்மூன்று வழக்கமான செயலிகளின் திரைகளும் கிடைக்கும்; அங்காடி தனியாகத் தொடரும். Android ஒப்புதலுடன் நிறுவுதல், கோப்பு/கையொப்பச் சரிபார்ப்பு, ரத்து மற்றும் பழைய பதிப்புக்குச் செல்லாத பாதுகாப்பு மாறவில்லை.

அதே கையொப்பத்தில் வழக்கம்போல் புதுப்பிக்கவும்; நீக்கவோ தரவை அழிக்கவோ வேண்டாம். புதிய அனுமதி அல்லது எல்லாச் சாதனப் பாதுகாப்பு ஒப்புதல் எனக் கூறவில்லை. இந்தப் பதிப்புக்கான உண்மையான CI/எமுலேட்டர் முடிவுகள் சரிபார்ப்புக் குறிப்பில் பதிவு செய்யப்படும்.
