# RP Vocal Remover Studio 0.1.13

No functional change. This version exists so the four-app batch can ship.

## Why this release exists

Live Guard and Ramesh Radio both publish in a four-app batch (Live Guard, Ramesh Radio, PulseEQ and
RP Vocal Remover Studio are released together, one tag per batch). The 20 October fixes could not be
published without a new Vocal Remover version, so 0.1.13 is the same app as 0.1.12 with the version
raised. If 0.1.12 already works for you, there is nothing new here — you can skip this update.

- Vocal reduction, the Slow / Medium / Fast selector, pause/resume, WAV output, optional 320 kb/s MP3
  export and the in-app guide are unchanged from 0.1.12.
- There is no new Android permission, and the model checksum is unchanged.
- The shared "sister apps" list now points at Live Guard 2.50 and Ramesh Radio 1.13.

## Installation and safety

Download `RP-Vocal-Remover-Studio-v0.1.13.apk` and install it through Android. If Android asks,
enable **Allow from this source** for the browser or file manager you used, then confirm in Android's
installer. No silent installation and no Play Protect bypass is used. The upgrade installs over
0.1.12 with the same signing key, so settings and exported files are kept.

லைவ் கார்டு, ரமேஷ் ரேடியோ, PulseEQ, வோக்கல் ரிமூவர் ஸ்டுடியோ — நாலும் ஒரே தொகுப்பாக வெளியிடப்படுகின்றன. 20 அக்டோபர் சரிசெய்தல்களை வெளியிட இதற்கும் புதிய பதிப்பு தேவைப்பட்டது; 0.1.13 என்பது 0.1.12-ஐப் போலவே இருக்கும் செயலி, பதிப்பு எண் மட்டும் உயர்ந்தது. 0.1.12 சரியாக வேலை செய்தால் இந்தப் புதுப்பிப்பைத் தவிர்க்கலாம்.

- வோக்கல் குறைப்பு, Slow / Medium / Fast, pause/resume, WAV வெளியீடு, விருப்ப 320 kb/s MP3 ஏற்றுமதி, வழிகாட்டி — 0.1.12-ஐப் போலவே.
- புதிய Android அனுமதி இல்லை; மாடல் checksum மாறவில்லை.
- பகிரப்பட்ட "சக செயலிகள்" பட்டியல் இப்போது லைவ் கார்டு 2.50, ரமேஷ் ரேடியோ 1.13-ஐச் சுட்டுகிறது.
