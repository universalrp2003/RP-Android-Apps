# வார வசூல் · Weekly Money 1.0

A Tamil-first, offline, single-owner weekly collection notebook. Record loans and receipts, keep correction history, manage book holidays and continue unpaid loans into a fresh volume. There is no automatic interest calculation. Optional contacts are encrypted and can be copied manually.

This is the completed single-owner scope; it does not provide collector exchange or sync. Keep an external encrypted backup and the master password: both are needed to restore on a fresh installation. A forgotten password cannot be reset by the developer. Backups kept only on the same phone may be lost with it.

The app label is now simply வார வசூல், including in Android's installer and biometric prompt. Version is in About. Update over the prior notebook version without uninstalling or clearing data: the package and persistent signing certificate are unchanged, version code 12. Back up first. APKs previously signed by other keys cannot necessarily update in place. Schema 6 can read schemas 1–5; do not downgrade after saving.

Built and checked using unit tests, lint, Android emulator regression and a synthetic 0.11-to-1.0 upgrade with the exact release APK. This is not an independent financial/security audit or a claim of testing on every physical device. Optional Tamil-date display is bounded to its supported 2026 table.
