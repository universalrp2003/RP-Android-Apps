# Voice Notes 1.3.2 — new-note visibility candidate

This exact version has no physical-device test and is not publicly released. Owner reports the earlier1.3.1/code5 works, including playback controls, but a newly dictated note is hidden above the current scroll position. That is not exact-byte acceptance of this candidate. Keep existing notes; do not uninstall.

- Newly dictated notes are revealed at the top of the notes list below the microphone. Previously, stable item keys preserved the old scroll anchor when a new note was prepended.
- Editing/deleting existing notes does not trigger this automatic jump. Normal user scrolling remains available.
- Stop/switch cancellation, HD-only voice, privacy consent, optional lock and opt-in daily in-app update checks preserved. External service availability is not guaranteed.
- Version code6. Unit/lint/signed package/signer/hash gates required; device layout validation remains pending.
