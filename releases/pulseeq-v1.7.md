# PulseEQ 1.7

No functional change. This version exists so the four-app batch can ship.

## Why this release exists

Live Guard and Ramesh Radio both publish in a four-app batch (Live Guard, Ramesh Radio, PulseEQ and
RP Vocal Remover Studio are released together, one tag per batch). The 20 October fixes could not be
published without a new PulseEQ version, so PulseEQ 1.7 is the same app as 1.6 with the version
raised. If 1.6 already works for you, there is nothing new here — you can skip this update.

- Twenty-band processing, presets, the spectrum view, local playback and the in-app guide are
  unchanged from 1.6.
- There is no new Android permission.
- The shared "sister apps" list now points at Live Guard 2.50 and Ramesh Radio 1.13.

## Installation and safety

Download `PulseEQ-v1.7.apk` and install it through Android. If Android asks, enable **Allow from this
source** for the browser or file manager you used, then confirm in Android's installer. No silent
installation and no Play Protect bypass is used. The upgrade installs over 1.6 with the same signing
key, so presets, saved tracks and settings are kept.

## ஏன் இந்த வெளியீடு

லைவ் கார்டு, ரமேஷ் ரேடியோ, PulseEQ, வோக்கல் ரிமூவர் ஸ்டுடியோ — நாலும் ஒரே தொகுப்பாக வெளியிடப்படுகின்றன. 20 அக்டோபர் சரிசெய்தல்களை வெளியிட PulseEQ-க்கும் புதிய பதிப்பு தேவைப்பட்டது; 1.7 என்பது 1.6-ஐப் போலவே இருக்கும் செயலி, பதிப்பு எண் மட்டும் உயர்ந்தது. 1.6 சரியாக வேலை செய்தால் இந்தப் புதுப்பிப்பைத் தவிர்க்கலாம்.

- இருபது பேண்ட் செயலாக்கம், presets, spectrum, உள்ளூர் இயக்கம், வழிகாட்டி — 1.6-ஐப் போலவே.
- புதிய Android அனுமதி இல்லை.
- பகிரப்பட்ட "சக செயலிகள்" பட்டியல் இப்போது லைவ் கார்டு 2.50, ரமேஷ் ரேடியோ 1.13-ஐச் சுட்டுகிறது.
