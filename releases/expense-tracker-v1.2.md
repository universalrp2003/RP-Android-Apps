# Expense Tracker 1.2 — fresh-install signing migration

**Version:** 1.2 · **versionCode:** 3 · **Package:** unchanged.

This release keeps the Expense Tracker 1.1 ledger and on-device privacy behavior. The Android signing identity changes because the former signing key was exposed; no network or SMS permission change is intended.

**Install warning:** Android cannot update an old-key installation with this APK. Export or back up anything important first, download this official APK, then uninstall the old app and install this version through Android. Uninstalling may erase local ledger data and settings. Do not uninstall before obtaining the replacement APK. Stop if Play Protect warns; do not bypass it.

The exact replacement-key APK was not installed on a phone. CI verification is not a device test or Play Protect clearance. The previous 1.1 tag and asset remain unchanged.
