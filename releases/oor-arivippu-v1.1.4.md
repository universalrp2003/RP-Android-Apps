# Oor Arivippu 1.1.4 (`versionCode = 9`) — Built-in Default `Tomorrow.io` 1-Minute Radar for Every Traveler (Zero API Key Needed)

## English Summary

Following real-world physical-device verification of **Oor Arivippu 1.1.3**, **Oor Arivippu 1.1.4** upgrades every traveler to **built-in `Tomorrow.io` 1-minute radar precision automatically by default — with ZERO API key required and zero new Android permissions**:

1. **Built-in Default `Tomorrow.io` 1-Minute Radar (`No Key Setup Needed`):**
   - Queries `Tomorrow.io`'s keyless `1m` + `1h` timelines directly from each phone with a 10-minute ~2 km tile cache so riders and drivers get accurate 1-minute rain & cyclone alerts out of the box without creating or pasting an API key (optional personal key still supported via Android Keystore).
2. **Multi-Model Anti-False-Positive Fallback (`MET Norway ECMWF` + Calibrated `Open-Meteo`):**
   - Eliminates false `"Rain starting now"` alerts on humid cloudy evenings and immediately refreshes any stale cached check upon launch.
3. **Full 2-Line Mini Alert Banner Headline:**
   - Displays full village/town + weather warning headlines cleanly across two lines without mid-word clipping.
