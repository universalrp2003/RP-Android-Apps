# Tamilan Store 0.5

First owner-authorized public release; updates 0.4-preview without uninstalling. Android 8+.

First-party twelve-app catalog with installed/Open/update states, verified download hashes and APK signer checks, real owner-supplied screenshot galleries, compact search, Help/About, email contact and app-request link. Optional silent daily reminders use the bundled catalog snapshot, not a live app feed. Store-update check discovers official stable releases and opens the browser; it does not automatically install updates. Existing apps retain their own self-updaters.

Owner tested the preceding preview on one phone; release build/signature checks are performed in CI. This is not all-device testing or an independent security audit. Screenshot galleries include earlier UI and some owner-approved data. No accounts or advertising. Do not uninstall to update.
