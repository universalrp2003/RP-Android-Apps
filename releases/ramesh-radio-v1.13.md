# Ramesh Radio 1.13

A search row that stays one line, and the last station starting by itself.

## Highlights

- **Fixed — the search box no longer grows three rows tall.** The நிலையப்பட்டியல் (station directory) control used to sit inside the text field as a wide chip, which left so little room that the Tamil hint wrapped onto several lines. It is now a compact icon square beside the field: same button, same action, 56 dp wide, and the hint is pinned to one ellipsised line in every language.
- **New — the station you played last starts when you open the app.** Ramesh Radio resumes it once per launch, after the player is ready.
- **It never fights another session.** If a widget, the notification or the lock screen already has audio playing, the app does not restart, rewind or pause it — automatic start only fills an idle player.
- **A saved switch in More** — *Start the last station when the app opens*. Off means the app opens quietly and waits for you to pick a station.
- No audio processing, station list, favourite or notification behaviour changed.
- There is no new Android permission.

## Installation and safety

Download `Ramesh-Radio-v1.13.apk` and install it through Android. If Android asks, enable **Allow from this source** for the browser or file manager you used, then confirm in Android's installer. No silent installation and no Play Protect bypass is used.

The upgrade installs over 1.12 with the same signing key, so favourites, saved stations, listening history and language are kept.
