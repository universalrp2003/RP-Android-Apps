The owner-selected replacement-key migration is implemented and verified in CI. Android cannot update an old-key installation with this APK. Download it from the official website, export/back up anything important, uninstall the old app, then install this version through Android. Uninstalling may erase local data. This exact replacement-key APK has not been installed on a phone; no Play Protect clearance is claimed. Do not bypass any security warning. Existing release assets are unchanged.
