# PulseEQ 1.6

A guide inside the app, in Tamil and English.

## Highlights

- **New — About → Guide.** Short questions that open when tapped: what the equalizer can change, why some phones do not let one app tune other apps' sound, how presets work, and what the app does not do.
- No audio-processing behaviour changed in this release.
- There is no new Android permission.

## Installation and safety

Download `PulseEQ-v1.6.apk` and install it through Android. If Android asks, enable **Allow from this source** for the browser or file manager you used, then confirm in Android's installer. No silent installation and no Play Protect bypass is used.
