# Live Guard 2.94 — SIM signal pill and compact home

- Movable status pill adds an approximate, coloured dBm-based signal estimate while unplugged. First installed SIM is the default; choose Both SIMs or Off under Home → Phone, network & security → Status Bar Pill & LED Meter. S1/S2 label physical slots; both use independent subscription readings. Missing/unsupported/permission-denied readings are hidden, never a copied SIM value, stronger neighbour, error placeholder or fake zero. If the normal signal API is missing, only a registered serving cell no older than60seconds can supply the radio-typed dBm. Because Android can combine dual-SIM cell lists, this fallback is restricted to one active SIM, existing precise-location permission and visible app UI. An overlay alone does not permit background cell reads. Ordinary independent per-SIM readings still work without location. No new permission prompt, identifiers stored/uploaded, server or polling service. Home/mobile signal details and unavailable usage/unknown pack balance also stay hidden; real measured zero remains valid.
- Existing data, three-segment D/U activity, move/drag/resize and saved Wi-Fi hiding remain. Charging retains watts-only mode; unplug restores the normal view.
- News defaults to Tamil + English-to-Tamil translation only when no explicit language choice exists. Saved English, app-language and Tamil-only selections and topics remain unchanged. Provider/network limitations still apply.
- Remove the empty permissions-row spacing above the first home card, reduce the list's top inset, and make only the home Scan & clean junk label/padding more compact while retaining font scaling and a minimum48dp touch target.
- Same package and signing identity as public2.93. Install as an update; do not uninstall or clear local data. Uninstalling may erase local data. No sibling app rebuild/publication is part of this release.

Verification status is recorded separately. Source/JVM/emulator evidence is not proof of all physical phones, real dual-SIM reception, audible translation, provider accuracy, or Play Protect clearance.

No physical-device test has been performed for this update; it is not installed on a phone by this build process. Do not bypass Android or Play Protect warnings. SHA256/signing checks identify exact bytes; they are not a Google safety clearance.

## தமிழ்

- சார்ஜர் இல்லாதபோது மிதக்கும் குறியில் dBm அடிப்படையிலான தோராய சிம் சிக்னல் நிறத்துடன் தெரியும். இயல்பாக முதலில் பொருத்திய சிம்; Home → Phone, network & security → Status Bar Pill & LED Meter பகுதியில் இரு சிம்கள் அல்லது வேண்டாம் என மாற்றலாம். S1/S2 சிம் இடங்களைக் குறிக்கும்; ஒவ்வொன்றிற்கும் தனித்தனி அளவீடு. கிடைக்காத சிக்னல்/விவரங்கள் பிழை அல்லது போலி பூஜ்ஜியமாகக் காட்டாமல் மறைக்கப்படும்; மற்ற சிம் அல்லது வலுவான அண்டை டவர் அளவு நகலாக்கப்படாது. வழக்கமான வாசிப்பு இல்லாவிட்டால்60விநாடிக்குள் உள்ள இணைந்த செல்லின் dBm மட்டுமே மாற்றாகும். இரு சிம் அறிக்கைகள் கலக்கலாம் என்பதால், செயலில் ஒரே சிம், ஏற்கனவே துல்லிய இருப்பிட அனுமதி, திரையில் திறந்த செயலி ஆகியவை இருந்தால் மட்டும் இந்த மாற்று வாசிப்பு. மிதக்கும் குறி மட்டும் பின்னணி செல் வாசிப்பை அனுமதிக்காது. புதிய அனுமதிக் கேள்வி, அடையாளச் சேமிப்பு/பதிவேற்றம், புதிய சுழற்சி இல்லை. வழக்கமான தனிச் சிம் வாசிப்பிற்கு இருப்பிடம் தேவையில்லை. உண்மையான பூஜ்ஜிய அளவு மறைக்கப்படாது.
- தரவு, மூன்று பகுதி D/U விளக்குகள், நகர்த்தல்/அளவு மற்றும் Wi-Fi விருப்பங்கள் தொடரும். சார்ஜில் வாட்ஸ் மட்டும்; சார்ஜர் நீக்கியதும் பழைய காட்சி மீண்டும் வரும்.
- முன்பு செய்தி மொழி சேமிக்காவிட்டால் தமிழ் + ஆங்கிலத்திலிருந்து தமிழாக்கம் இயல்பு. ஏற்கனவே தேர்ந்தெடுத்த மொழியும் தலைப்புகளும் மாறாது. மொழிபெயர்ப்பு சேவையின் வரம்புகள் தொடரும்.
- முகப்பில் காலியான அனுமதி வரிசையால் ஏற்பட்ட இடைவெளி நீக்கம்; முதல் அட்டைக்கு மேலான இடைவெளி குறைப்பு; ஸ்கேன் பொத்தானின் எழுத்து/உள் இடைவெளி சீராக்கம். எழுத்தளவு அணுகல்தன்மையும்48dp தொடு இலக்கும் தொடரும்.
