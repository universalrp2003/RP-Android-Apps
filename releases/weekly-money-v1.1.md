- தொடர்பு எண் பெட்டி சரிசெய்யப்பட்டது. Screenshot கட்டுப்பாடு Settings-ல் உள்ளது.
- இன்று வசூல் கிழமைக்கான புத்தகம் நேரடியாகத் திறக்கும். Back முந்தைய பகுதிக்குச் செல்லும்.
- Login பக்கத்தில் விருப்பமான இணைய update check; தானாக நிறுவாது.
- ஒரே நேரத்தில் ஒருவர் மட்டும் பதிவிடும் backup handoff: பழைய அல்லது முரண்பட்ட பதிவுகளை மாற்றாது. இது தானியங்கி merge அல்ல; மற்ற phone-ல் பகிராத மாற்றங்களை அறியாது.
- Settings-ல் password மாற்றும்போது புதிய password backup முதலில் சேமிக்கப்படும். **பழைய backup-களுக்கு பழைய password தேவை.**
