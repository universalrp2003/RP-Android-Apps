# விலங்கு ஒலிகள் · Animal Sounds 0.21

- **Built-in Guide and About, reachable from ⚙ Settings.** Settings ends with a **Guide & about** card. The guide has 12 bilingual topics: what this app does, the first download (about 79 MB), 3 seconds or 9 seconds, reading the results, reference photos, YAMNet, the species model files, what it cannot do, privacy, language, settings and tips. **About this app** carries the team details (Ramesh prathap .R, universalrp2003@gmail.com · RP Ideas; software assistance: Arena.ai Agent Mode), the official website link, the GitHub repository link, the update policy, the model licences, and the shared directory of all 18 RP Ideas apps.
- **Daily update notice.** Once a day the app reads only public release metadata from the official website and shows an "update available" card when a newer release exists. Tapping it opens the official website in a browser. Nothing is downloaded or installed by the app. Audio never leaves the phone.
- The interface language (English / தமிழ்) is now kept in the shared RP Ideas preference, so the app, its Guide and its About always agree.
- Version 0.21 (version code 21). Signed with the same key as 0.17–0.20, so it installs over 0.20 in place and keeps the downloaded model and settings.
- **Device test status:** the exact 0.21 bytes were not installed on a phone before publication. CI ran the unit tests and the Android 15 emulator suite (main screen, Settings, Guide and About at 1.0× and 2.0× font scale in both languages). This is not an independent security audit.
