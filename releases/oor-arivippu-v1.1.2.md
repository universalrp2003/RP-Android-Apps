# Oor Arivippu 1.1.2 — Stable

A direct Guide button is now on the home screen. Voice settings take less space until opened, and the speaking volume can be set inside the app.

## Highlights

- **Guide on Home:** tap the help icon in the top row to open the bilingual, expandable Oor Arivippu guide. It explains location tracking, destination matching, approximate distance alerts, voice and language choices, travel/repeat settings, offline reminders and privacy.
- **Compact settings:** App language and Voice language are separate tap-to-open rows. App language changes the interface; the expanded voice controls include announcement language, Android TTS voice, speech speed and a test action.
- **Speech-volume slider:** set the level used by Oor Arivippu's spoken announcements from 0% to 100%. The preference is saved on this phone; it does not change the phone's media volume. New installs start at 100%.
- **Offline reminders:** the app uses an installed on-device TTS voice or a short beep, not a network voice. Some selected Android voices may send spoken text to their provider; the voice picker marks voices that need internet.
- No new Android permission. Location/geocoder behavior and destination announcements are otherwise unchanged.

## Installation and safety

Download `Oor-Arivippu-v1.1.2.apk` from the official release and install it through Android. If Android asks, enable **Allow from this source** for the browser or file manager you used, then confirm in Android's installer. No silent installation or Play Protect bypass is used.

## Verification and device testing

The exact APK was not installed on a phone before publication. The standalone workflow runs release unit tests, release lint, the signed build and package/version/certificate/asset checks. CI success is not an all-device compatibility claim.
