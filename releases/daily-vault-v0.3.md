# DailyVault 0.3

First owner-authorized public release; updates 0.2-preview without uninstalling. Android 8+.

Manual spending entries with totals, timestamps, private notes/history and password-encrypted portable backup/restore. Optional phone biometric/device-credential app opening or no-app-lock mode; backup/restore still requires the vault password. Device unlock is a local access gate, not biometric-bound encryption. No cloud sync, automatic backup or password recovery. Restore replaces records rather than merging: export a backup before restoring. Losing the password can mean losing access. Keep and test backups outside the app before uninstalling or changing phones.

Owner accepted the preceding preview on one device. Release build/signature checks are performed in CI; cancellation, key invalidation and cross-device restore are not claimed exhaustively tested. Screen capture protection remains enabled. No Internet permission, accounts or ads.
