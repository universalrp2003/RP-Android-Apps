# Ramesh Radio 1.32

## English

- A light green layout shows more stations, with a side navigation menu and a separate Artists tab. The mini-player and saved station lists remain available.
- Back returns from the directory or a menu screen. Changing a category clears the old search, and the search box has a clear button.
- Artist cards search station names inside the app. Spotify links have been removed. Many artist searches have no matching in-app audio; a match does not guarantee the artist is playing. Some streams are unavailable or held for review.
- General Tamil music and health stations are no longer presented as dedicated Tamil news. Verified continuous Tamil news audio is not yet available in the shipped list.
- Weather limitation found after publication: the 1.32 interface has no weather settings controls, but retained weather code can still run while audio is playing. If weather is enabled and a place is saved, it may send that place’s coordinates to forecast providers; the existing code may also enable weather when device location is on and no explicit choice was saved. You cannot change these settings in the 1.32 interface.
- The exact release APK has not been tested on a physical phone. Emulator and build checks do not prove station identity, licensing, content or current availability.
- Update without uninstalling where the signing key matches. Uninstalling may erase local data, favourites and custom stations. Back up important data first.

## தமிழ்

- எளிய பச்சை நிறத் தோற்றத்தில் அதிக நிலையங்கள் தெரியும். பக்கப் பட்டியலும் தனிக் கலைஞர் தாவலும் உள்ளன; இயக்கக் கட்டுப்பாடுகளும் சேமித்த நிலையங்களும் தொடரும்.
- திரும்பும் பொத்தான் பட்டியல் அல்லது பிற திரைகளிலிருந்து வானொலிக்குத் திரும்ப உதவும். வகையை மாற்றும்போது பழைய தேடல் அழியும்; தேடலை அழிக்கவும் பொத்தான் உள்ளது.
- கலைஞர் அட்டைகள் செயலிக்குள் நிலையப் பெயர்களைத் தேடும். வெளி இசைச் சேவை இணைப்புகள் நீக்கப்பட்டன. பல கலைஞர்களுக்குப் பொருந்தும் ஒலித் தொகுப்பு இன்னும் இல்லை; பெயர் பொருத்தம் அந்தக் கலைஞரின் பாடல் ஒலிப்பதை உறுதி செய்யாது. சில நிலையங்கள் கிடைக்காமல் இருக்கலாம் அல்லது பரிசீலனையில் உள்ளன.
- பொது இசை மற்றும் உடல்நல நிலையங்கள் தனிச் செய்தி நிலையங்களாகக் காட்டப்படாது. தொடர்ந்து தமிழ்ச் செய்தி ஒலிக்கும் சரிபார்க்கப்பட்ட இணைப்பு இன்னும் சேர்க்கப்படவில்லை.
- வானிலை குறைபாடு: இந்தப் பதிப்பில் வானிலை அமைப்புப் பொத்தான்கள் இல்லை. ஆனால் வானிலை இயக்கப்பட்டு ஊர் சேமிக்கப்பட்டிருந்தால், ஒலி இயங்கும்போது அதன் ஆயத்தொலைகள் வானிலைச் சேவைகளுக்கு அனுப்பப்படலாம். முன்பு தேர்வு செய்யாதபோது கைபேசியின் இருப்பிட அமைப்பு இயக்கத்தில் இருந்தால் வானிலை தானாக இயங்கவும் வாய்ப்புள்ளது. இதை இப்பதிப்பின் திரையில் மாற்ற முடியாது.
- வெளியீட்டுக் கோப்பின் ஒலி நேரில் கைபேசியில் சோதிக்கப்படவில்லை. கணினிச் சோதனை நிலையத்தின் அடையாளம், உரிமை, நிகழ்ச்சி அல்லது தற்போதைய செயல்பாட்டை உறுதி செய்யாது.
- கையொப்பம் பொருந்தினால் நிறுவல் நீக்கம் செய்யாமல் புதுப்பிக்கவும். நிறுவல் நீக்கினால் உள்ளூர் தரவு அழியலாம்; விருப்ப நிலையங்களும் சொந்த நிலையங்களும் இழக்கப்படலாம். முக்கியத் தரவை முதலில் காப்பெடுக்கவும்.
