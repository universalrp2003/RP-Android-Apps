# Vasanthi AI 1.1.4

## Help and updates

- About now includes the shared verified APK updater alongside the existing guide and sister-app/project links.
- Updater configuration pins this app's package and uses the existing official-release, digest and signing-certificate verification. Android still asks for per-app installation access and confirmation.
- System Back now leaves the guide and returns to the main screen. Safe-area padding keeps shared help pages away from system bars.
- Existing audio and speech behaviour is unchanged; this release does not claim to solve every manufacturer's microphone or volume behaviour.

## Testing limits

- This exact build is **not installed on a phone** and has **no physical-device test** in this session. CI is not proof of a successful update installation or a microphone/volume test.
