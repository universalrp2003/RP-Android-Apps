# வார வசூல் · Weekly Money 1.3

- Login செய்த பிறகும் முகப்பில் **புதிய பதிப்பு பார்க்க / Check for updates** பொத்தான் தெரியும். புத்தகம் நேரடியாகத் திறந்தால், ‹ புத்தகங்கள் தொட்டு முகப்புக்குச் செல்லுங்கள்.
- Login திரையிலும் அதே பொத்தான் தொடர்ந்து கிடைக்கும். பொத்தானைத் தொட்டால் மட்டும் இணையத்தில் அதிகாரப்பூர்வ பட்டியலைப் பார்க்கும்; புதிய பதிப்பு இருந்தால் அதிகாரப்பூர்வ பதிவிறக்கப் பக்கத்தைத் திறக்கலாம். தானாக எதையும் நிறுவாது.
- தமிழ் வழிகாட்டியில் பொத்தான் இருக்கும் இடம் தெளிவுபடுத்தப்பட்டுள்ளது.
