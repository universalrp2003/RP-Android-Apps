# குறிப்பு · Note (candidate)

Separate Android 8+ offline notebook, not yet published. Create sections one below another; choose whether each section totals amounts. The heading செலவு or Expense enables totals by default; other headings start as notes, and the switch can be changed before saving. Each entry has a growing, multiline note. In amount sections, enter a separate positive or negative decimal amount (up to two decimal places); a sign button is provided. Totals are exact decimal arithmetic, not guesses based on numbers in the note. Notes-only sections do not calculate. Tap or long-press an entry for created/last-edited date and time, edit, or delete. Section deletion asks for confirmation and also deletes its entries. Section names can be changed; section type cannot be switched after creation.

Notes live in the app's private local database. There is **no backup, sync, transfer, encryption or recovery feature in this candidate**: uninstalling, clearing data, resetting or losing the phone loses them. Do not use it for the only copy of important records. It does not access the internet. Device-clock changes affect displayed timestamps. This candidate needs owner testing before publication.
