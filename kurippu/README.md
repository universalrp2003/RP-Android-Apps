# குறிப்பு · Note 1.0

An offline ruled Android notebook. [Download 1.0](https://github.com/universalrp2003/RP-Android-Apps/releases/tag/kurippu-v1.0). Switch between **செலவு** (expense with amount and total) and **குறிப்பு** (full-width note without a total) at the top. The plus button adds a page with its own heading; choose Note for a full-width page, or Total for a page with amounts. Long-press a page tab to rename or delete it (delete requires confirmation and permanently removes that page’s rows). Long-press and drag a page tab to reorder it; Settings also has left/right order buttons. The order is stored locally. A separate Calculator page supports addition, subtraction, multiplication and division, and never changes notebook entries. The last six complete calculations appear below the keypad for the current app session; C starts a new calculation without erasing those lines. Calculator history is not saved when the app closes. Calculations are left-to-right. Repeating divisions are marked approximate; division by zero reports an error. Settings offers an on/off dark mode. Type directly in the rows; extra blank lines appear automatically and notes grow vertically.

Settings (⚙) applies the second-column and total switches to the current page. Hiding the column turns its total off but **does not delete** its existing values; turn the column on again to see them. Turning the column back on does not automatically restart the total. Existing 0.3 notes with right-column content retain their visible column on upgrade so no information disappears; empty note pages become full width. Invalid non-numeric amounts prevent showing a misleading total.

Select all / Copy can be turned on or off in Settings. It selects and explicitly copies the current page only, including every non-empty row, values (even hidden ones), timestamps and, when active and valid, the total. The clipboard may be visible to Android or other apps depending on the device; copying is never automatic. Long-press a row to see created/last-edited times or delete with confirmation. Device-clock changes affect timestamps.

Amounts allow negatives, up to 18 digits before the decimal point and 2 after it. A blank amount is not counted; numbers in the text column are never added. Existing 0.1 through 0.4 records and times are preserved, including page preferences. Android 8+; no internet access.

**No backup, sync, transfer, encryption or recovery yet.** Notes live in the app's private local database. Uninstalling, clearing data, resetting or losing the phone loses them. Don't use this app as the only copy of important records.
