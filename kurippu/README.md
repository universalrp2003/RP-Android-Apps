# குறிப்பு · Note (candidate)

An offline ruled notebook, not yet published. Switch between **செலவு** (expense, with a total) and **குறிப்பு** (notes, no calculation) at the top. Both pages have editable rows with two columns that grow for text. The plus button lets you add a page with a heading and choose whether it totals amounts. Each calculating page has its own independent total; a notes page accepts text in either column and never adds it. Type directly in the rows; extra blank lines appear as needed.

Amounts accept up to 18 digits before the decimal point and 2 after, including negatives. A blank amount is not counted; numbers in the left column are never added. An incomplete/invalid amount replaces the total with a warning rather than silently omitting it. Long-press a row to see its creation and last-edit time or delete it with confirmation. Device-clock changes affect timestamps.

Existing 0.2 rows move intact to the செலவு page, including text, amounts and timestamps. Earlier 0.1 section titles become plain rows and all old entries remain; original 0.1 section tables are retained. Android 8+; no internet access.

**No backup, sync, transfer, encryption or recovery yet.** Notes live in the app's private local database. Uninstalling, clearing data, resetting or losing the phone loses them. Don't use this candidate as the only copy of important records. It needs owner testing before publication.
