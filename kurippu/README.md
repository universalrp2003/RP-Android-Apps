# குறிப்பு · Note (candidate)

A simple offline Android notebook, not yet published. Type directly into the ruled rows: note on the left, optional amount on the right. Rows grow for longer notes, and additional blank rows appear as needed. The bottom shows the exact decimal total, including negative numbers. An empty amount is a note and contributes nothing; numbers inside note text are never added. Amounts accept up to 18 digits before the decimal point and up to 2 after it. If an amount is incomplete or invalid, the total instead asks you to check the amounts. Long-press a row to see its creation and last-edit date/time or delete it (with confirmation).

The update converts existing 0.1 section titles into plain rows, and preserves all old entries, amounts and timestamps. The earlier version did not record times for section titles. The old database tables are also retained. Device-clock changes affect displayed timestamps. Android 8+; no internet access.

**No backup, sync, transfer, encryption or recovery yet.** Notes live in the app's private local database. Uninstalling, clearing data, resetting or losing the phone loses them. Don't use this candidate for the only copy of important records. Candidate needs owner testing before publication.
