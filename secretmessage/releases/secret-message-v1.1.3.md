# Secret Message 1.1.3

Updates the in-app **About** section to include the **RP-Android-Apps Official Website (`universalrp2003.github.io/RP-Android-Apps/`)** and all **7 official RP Ideas Android apps**, including **`SMS Guard (குறுஞ்செய்தி காவலன்)`**, in both Tamil and English.

**Not independently security-reviewed.** No outside security expert has reviewed this app, and the mls-rs library has not had a full third-party audit. Do not rely on it where your safety depends on secrecy.

## What's new

- **Official Website link in About:** adds a direct one-tap link to **`https://universalrp2003.github.io/RP-Android-Apps/`** right alongside **Official downloads — RP-Android-Apps** and **Source code — InternetRadio**.
- **All 7 RP Ideas apps in About:** adds **`SMS Guard (குறுஞ்செய்தி காவலன்)`** and refreshes every RP Ideas app link (`1.1.1`, `2.63`, `1.19`, `1.9`, `0.1.15`, `1.1.6`, `1.1.3`) in Tamil and English.
- No change to the MLS protocol, encryption, message expiry, relay, or call behavior. No new Android permission.

## What the relay can see

Both phones' IP addresses, connection times and traffic sizes, and the start of each session before the safety-code check (invite token, device IDs and public keys). It cannot read messages, drawings or pictures. The relay forwards bytes and does not keep a chat history; connection metadata remains visible to the relay operator and Cloudflare's account-level service statistics may exist.

## Install and verification

`Secret-Message-v1.1.3.apk` supports Android 8.0 (API 26) or newer and installs over 1.1.2 with the same project signing key (`58e370e417cf6f33234689acd5bf379474f5a8c55f79181d9e892a321bc04f08`). Build, unit tests, signing checks and the hosted API 35 emulator smoke test are run by the standalone workflow. The exact APK was not installed on a phone before publication; an emulator check is not a physical-device test.
