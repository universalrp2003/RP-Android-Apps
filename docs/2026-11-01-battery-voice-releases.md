## Research

Read Android's BatteryManager API: https://developer.android.com/reference/android/os/BatteryManager . CURRENT_NOW is instantaneous **microamps**, positive into battery/negative discharge; unsupported modern-target properties return Integer.MIN_VALUE (or an exception). Battery status FULL is different from percentage. Battery current is not adapter output; exact charger power cessation cannot be guaranteed by this API. Unsupported-zero OEM evidence is already documented in BatteryValuePolicy and must not be regressed.

Read Android Thermal API guidance: https://developer.android.com/games/optimize/adpf/thermal . Thermal status/headroom support and interpretation vary; unavailable/zero status is not proof of cool CPU. Do not reinterpret a raw thermal-zone maximum as an interchangeable CPU sensor or add another speculative spoken warning. No new thermal permission or sensor provider is added.
