# Owner reference screenshots — station reconciliation in progress

The owner provided 38 screenshots. `tools/radio_reference/screenshot-inventory.txt` is a working, manual visual transcription in chronological screenshot order; repeat tiles and uncertain/cropped labels are retained. The 524 different labels include repeated variants, generic descriptions, artist shortcuts, and placeholders — they are **not** a count of distinct stations. The screenshots themselves are not included in this repository.

`tools/radio_reference/name-review.csv` is a mechanically generated **name-only** queue. A match is not evidence of station identity or current service, while an unresolved row does not mean the station is unavailable. Spellings, Tamil/English names, and truncated labels need manual review. Generate it using `python3 tools/radio_reference/coverage.py tools/radio_reference/name-review.csv`. The 392 bounded Radio Browser queries (Tamil language and tags plus distinct reference tokens) returned 2,205 unique directory records and no query failures during CI run 46028694004. ## Finding the reference labels in the app

The screenshot spellings stored as `referenceName` are now searchable alongside the actual station name and metadata. This helps find e.g. Nattrinai → Natrinai FM, Thoani FM → Thoni FM 91.2, and Shyamala Vani → Shyamalavani, including unverified/offline entries. Where the names differ, the station detail and list view explicitly mark the screenshot wording as a **possible, unconfirmed** correspondence. Searching a label does not assert identity or playback. The earlier 613 station IDs are protected by an offline retention test, and categories, favorites, and stream URLs remain unchanged.
