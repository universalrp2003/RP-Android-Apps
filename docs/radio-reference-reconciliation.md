# Owner reference screenshots — station reconciliation in progress

The owner provided 38 screenshots. `tools/radio_reference/screenshot-inventory.txt` is a working, manual visual transcription in chronological screenshot order; repeat tiles and uncertain/cropped labels are retained. The 524 different labels include repeated variants, generic descriptions, artist shortcuts, and placeholders — they are **not** a count of distinct stations. The screenshots themselves are not included in this repository.

`tools/radio_reference/name-review.csv` is a mechanically generated **name-only** queue. A match is not evidence of station identity or current service, while an unresolved row does not mean the station is unavailable. Spellings, Tamil/English names, and truncated labels need manual review. Generate it using `python3 tools/radio_reference/coverage.py tools/radio_reference/name-review.csv`. The 392 bounded Radio Browser queries (Tamil language and tags plus distinct reference tokens) returned 2,205 unique directory records and no query failures during CI run 46028694004. Their contents are not a complete list of all stations on the internet; returned matches still need individual inspection.

The first three manually reviewed candidate batches and their bounded FFprobe results are retained in `tools/radio_reference/{first,second,artist}-probe-receipt.json`; the CI runs were 46028607604, 46029653460 and 46030621342. Twenty-seven reference-related endpoints from these batches were added to the seed. Their `verified` flag means audio metadata was reachable from the runner, **not** that anyone listened to the content, checked copyright/rebroadcast permissions, confirmed the exact stream belongs to the reference tile, or tested phone and regional availability. Station content and availability can change. The original directory information is user-contributed, and direct URL lists may be stale. Station-hosted logos are used only when identified; missing images fall back to initials.
