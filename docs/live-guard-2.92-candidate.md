## Measurement, delivery and privacy boundaries

- SIM percent is Android's relative0–4 level times25, not a dBm-to-percent model or an invented89%. Invalid levels are not clamped to100%. Unknown zero-without-readable-dBm stays neutral unknown on Home. Real network/dBm retained. Phone permission requested only by user action.
- Headline controls occupy a separate top row; Read no longer consumes headline width. No fixed line limit on the actual headline. All text retains font scaling and accessible touch targets.
- Rain copy is Live Guard-only, via RainNoticePolicy/SimpleWeatherPolicy; shared providers/episode memory/precise-minute entitlement gates and cyclone speech are not changed. Forecast/approximate qualifications retained, unknown timing not invented30minutes.
- Widget uses a small bounded local cache (<=3 reports/6000 JSON characters on read), populated only from already-verified existing news candidates for the saved-home region. A distant moving GPS origin clears it. Home changes, master disaster OFF, stale/future/malformed reports hide it. TC requires a verified observation time; EQ/FL use dated reports. TC<=2000km,FL<=500km,EQ<=300km regional-reference bounds, not local impact predictions. Source/time/qualification travel with the report; small widgets omit the extra view to protect controls. No new request, host, worker, APK/sample upload or spoken/notification ledger mutation. Provider details stay in-app; widget uses forecast/model labels rather than misleading Radar.
- Quiet beep is a new ASK_FIRST feature with stable discovery ID `no_signal_beep`, defaultOFF, Enable/Not now and Mobile split-card switch. Its preference never changes the voice master. The existing RadioWatchService is needed while this option is enabled (and retains its ongoing notification); existing boot/resume start restrictions remain. No additional loop/worker. Default data subscription only; switching subscriptions resets episode memory. READ_PHONE_STATE, valid ready SIM, airplane OFF, in-service baseline then confirmed out-of-service plus zero level are required. Unknown/unavailable/service-powered-off/emergency-only are not signal loss. Android26–27 do not beep without a readable supported signal level.
- Pure episode policy requires30s stable in-service then15s loss; after one attempt, continuous loss never repeats.30s stable recovery rearms. Unknown/permission loss/clock reversal resets. Suppressed episodes are not replayed later. System monotonic clock, no persistent subscriber identities or server telemetry.
- ToneGenerator uses media stream, gain10/100 and a single120ms tone, released after180ms or service teardown. Never changes volume, ringer, DND or focus. Rechecks call/VoIP/quiet hours/silent place, ringer/DND, active media/voice, airplane and media mute before a tone. Unsafe state on a later service sample stops any active tone. Physical loudness/headset/OEM/provider/modem freshness and background lifetime are not proven by synthetic tests; no emergency/no-signal delivery guarantee.
