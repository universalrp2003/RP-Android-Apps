# குறிப்பு · Note 1.1

The calculator now places × above a wider = button and shows the last six completed calculations below the keypad. C starts a new calculation and keeps the displayed history. History is temporary and disappears when the app closes; arithmetic runs left to right. The notebook remains offline and supports pages, amounts and totals, dark mode, page ordering, rename and delete.

**No backup or sync:** uninstalling, clearing app data, resetting or losing the phone removes notes. Update over the existing app without uninstalling or clearing data.

The owner installed the 1.1 candidate and confirmed it works, providing screenshots of the calculator history and page menu. The installed phone file hash was not independently checked. CI passed ten native Android tests and a signed in-place 1.0-to-1.1 upgrade with synthetic data. This release contains the exact CI-tested signed APK, not a rebuild. A separate 1.2 candidate adds the About guide and is not included in this 1.1 release.
