# குறிப்பு · Note 1.0

An offline ruled notebook for Android 8 and later. Use separate pages for notes or amounts and totals; rename, reorder or delete pages, and optionally copy the current page. A separate calculator supports addition, subtraction, multiplication and division. Dark mode is available.

Notes stay on the device. There is **no backup or sync**: uninstalling, clearing app data, resetting or losing the phone removes them. When updating, install over the existing app without uninstalling or clearing data.

The owner tested 0.6 on a phone and authorized these final calculator changes and publication. The 1.0 calculator changes were tested on an Android emulator, not yet on the owner's phone. CI verified nine Android tests and an in-place signed 0.6-to-1.0 upgrade using synthetic data. This release contains the exact tested signed APK, not a rebuild.
