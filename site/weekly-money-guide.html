முக்கியம்: உங்கள் Master password-ஐ பாதுகாப்பாக எழுதிவையுங்கள். சமீபத்திய backup file-ஐ இந்த phone தவிர வேறு இடத்திலும் வையுங்கள். இரண்டும் இருந்தால்தான் புதிய phone-ல் உங்கள் நோட்டை மீட்க முடியும்.

0. உரிமையாளர் / நிறுவனம் / தொழில் பெயர்

முதலில் நோட்டை உருவாக்கும்போது பெயர் கொடுக்க வேண்டும். தனியாகப் பயன்படுத்தினால் உங்கள் பெயரை வைக்கலாம். பலர் ஒரே நோட்டைப் பயன்படுத்தினால் எல்லோருக்கும் பொதுவான நிறுவனம் அல்லது தொழில் பெயரை வையுங்கள்; உதாரணம்: நமது தொழில். இது உதாரணம் மட்டும். உருவாக்கிய பிறகு இந்த app-ல் பெயரை மாற்ற முடியாது; எனவே சரிபார்த்து அமைக்கவும். நோட்டின் முகப்பில் இந்தப் பெயர் தெரியும்.

இந்தப் பெயர் backup-லேயே சேமிக்கப்படும். புதிய phone-ல் restore செய்தால் முதல் நோட்டில் இருந்த அதே பெயரும் பதிவுகளும் திரும்ப வரும்; புதிய நபரின் பெயர் கேட்கப்படாது. எல்லோரும் அதே பொதுப் பெயரைப் பயன்படுத்துவார்கள். ஒவ்வொருவருக்கும் தனி பெயர் அல்லது யார் எந்தப் பதிவைச் செய்தார் என்று காட்டும் வசதி இல்லை. தனித்தனியாக ஒரே பெயரில் நோட்டுகளை உருவாக்கினாலும் அவை ஒரே நோட்டாகாது; முதலில் ஒரே backup-ஐ restore செய்துதான் பகிர்ந்து தொடங்க வேண்டும்.

1. Master password ஏன்?

இது உங்கள் நோட்டையும் backup file-ஐயும் திறக்கும் முக்கிய password. Phone PIN வேறு. குறைந்தது 10 எழுத்துகள் தேவை. பெரிய/சிறிய ஆங்கில எழுத்து, எண், குறியீடு கலந்து, மற்றவர் ஊகிக்க முடியாத ஒன்றைத் தேர்வு செய்யுங்கள். உதாரணம் மட்டும்: Maram!Mazhai42. இதையே பயன்படுத்தாதீர்கள். Password-ஐ எழுதி phone-க்கு வெளியே பாதுகாப்பாக வையுங்கள். வேறு யாருடனும் தேவையில்லாமல் பகிர வேண்டாம்.

2. Backup என்றால் என்ன?

முழு நோட்டின் பூட்டப்பட்ட நகல். பெயர், புத்தகம், கடன், வசூல், திருத்த வரலாறு எல்லாம் அதில் இருக்கும். அதைத் திறக்க backup எடுத்தபோதுள்ள password தேவை. Password மட்டும் இருந்தால் நோட்டை மீட்க முடியாது; backup file-மும் தேவை.

3. Backup எங்கே கிடைக்கும்?

Android 10 அல்லது அதற்குப் பின்: Downloads → WeeklyMoney. Android 8/9: Settings → Backup folder-ல் ஒரு folder தேர்வு செய்யுங்கள். Settings → Backup now தொட்டும் நகல் எடுக்கலாம். வாரத்தின் முதல் மாற்றத்திற்கு முன், வசூல் முடித்த பிறகும் app திறந்து இருக்கும்போது backup எடுக்கும். வாரம் தொடங்கியதற்காக பின்னணியில் தானாக எடுக்காது.

4. கட்டாயம் வேறு இடத்தில் நகல் வையுங்கள்

Downloads அதே phone-ல் தான் உள்ளது. Phone தொலைந்தாலோ, பழுதானாலோ, reset செய்தாலோ அதுவும் போகலாம். புதிய .vvasool file-ஐ வேறு phone, USB அல்லது உங்கள் Drive-க்கு நீங்களே நகலெடுக்கவும். App தானாக Drive-க்கு அனுப்பாது. அடிக்கடி புதிய நகல் எடுத்து, பழைய பாதுகாப்பான நகல்களையும் வைத்திருங்கள். Backup தோல்வி செய்தி வந்தால் இடவசதி/folder சரிபார்த்து Settings → Backup now முயற்சி செய்யுங்கள். வார முதல் backup தோல்வியால் பதிவு நிறுத்தப்படும்; வசூல் முடித்த பின் backup தோல்வியானால் உள்ளூர் பதிவு இருக்கும், மீண்டும் backup எடுக்க வேண்டும்.

5. Phone தொலைந்தால் அல்லது புதிய phone-ல்

வேறு இடத்தில் வைத்துள்ள சமீபத்திய .vvasool backup file-ஐ புதிய phone-க்கு கொண்டு வாருங்கள். அதிகாரப்பூர்வ app-ஐ நிறுவுங்கள். காலியான app-ல் Restore a full backup தேர்வு செய்து file-ஐத் தேர்ந்தெடுங்கள். அந்த file எடுத்தபோதுள்ள password-ஐ உள்ளிடுங்கள். பெயர், புத்தக எண்ணிக்கை பார்த்து Confirm restore அழுத்துங்கள். மீட்ட பிறகு விவரங்களைச் சரிபார்த்து புதிய backup எடுத்து வேறு இடத்தில் வையுங்கள். Backup அல்லது அதற்கான password இல்லையெனில் பழைய பதிவுகளை மீட்க முடியாது. எங்களாலும் password-ஐ மீட்டுத் தரவோ backup-ஐத் திறக்கவோ முடியாது.

6. Password மாற்றினால்

Settings → Change password. தற்போதைய password, புதிய password, அதையே மீண்டும் உள்ளிடுங்கள். முதலில் புதிய password-ல் backup பாதுகாப்பாக சேமிக்கப்பட்ட பிறகே phone-ன் password மாறும். அந்த புதிய backup-ஐ வேறு இடத்துக்கும் நகலெடுக்கவும். முன்பு எடுத்த backup-கள் மாறாது: அவற்றைத் திறக்க அவை எடுக்கப்பட்ட நேரத்தின் பழைய password தேவை. பழைய password-ஐயும் எந்த backup-க்கானது எனக் குறிப்பிட்டு பாதுகாப்பாக வையுங்கள். புதிய backup-களுக்கு புதிய password தேவை. Fingerprint பயன்படுத்தினால் மாற்றத்திற்குப் பிறகு Settings-ல் மீண்டும் இணைக்கவும்.

7. Fingerprint

இது இந்த phone-ல் சுலபமாகத் திறப்பதற்கு மட்டும். புதிய phone, backup restore அல்லது fingerprint வேலை செய்யாதபோது Master password தேவை. Fingerprint மட்டும் password-க்கு மாற்று அல்ல.

8. இரண்டு அல்லது மூன்று உரிமையாளர்கள்

ஒரே பொதுவான நிறுவனம் / தொழில் பெயர் எல்லா phone-களிலும் தொடரும். புதிய phone-ல் முதலில் அதே backup-ஐ காலியான app-ல் restore செய்யுங்கள்; வேறு பெயரில் புதிய நோட்டு உருவாக்க வேண்டாம். யார் பதிவு செய்தார் என்பதை app தனியாகக் காட்டாது. ஒரே நேரத்தில் ஒருவர் மட்டும் பதிவிடுங்கள். வேலை முடிந்தவர் சமீபத்திய முழு backup-ஐ மற்றவருக்கு அனுப்பி, தன் பழைய நோட்டில் மேலும் எழுதுவதை நிறுத்த வேண்டும். Password-ஐ நம்பகமானவருக்கு பாதுகாப்பாகத் தனியாகத் தெரிவிக்கவும். மற்றவர் தன் நோட்டைத் திறந்து Settings → Open shared backup-ல் file மற்றும் அந்த file-ன் password கொடுத்து விவரங்களைப் பார்க்கவும். பொருந்தினால் உறுதி செய்த பிறகு பழைய உள்ளூர் நோட்டுக்கும் recovery backup எடுத்து புதிய முழு நோட்டை ஏற்கும். அந்த phone-ன் சொந்த password மாறாது. பழைய அல்லது வேறுபட்ட பதிவுகள் இருந்தால் app மாற்றாது; இரண்டு backup-களையும் வைத்துக் கொண்டு உரிமையாளர்கள் சரிபார்க்கவும். App இரு phone பதிவுகளைத் தானாக இணைக்காது; மற்ற phone-ல் பகிராத மாற்றம் உள்ளதா என்றும் அறியாது.

9. தினசரி பயன்பாடு

புத்தகம் உருவாக்கி வசூல் கிழமையைத் தேர்வு செய்யுங்கள். கடன் சேர்க்க இடம் → குடும்பத் தலைவர் → வாடிக்கையாளர், தேதி, இறுதி மொத்தம் உள்ளிடுங்கள். வட்டி கணக்கிடப்படாது. தொடர்பு எண் விருப்பம்; விவரத்தில் எண்ணைத் தொட்டால் copy செய்து Phone-ல் paste செய்யலாம். பெயரைத் தொட்டு வாரத் தொகைகளைப் பதிவு செய்யவும். பழைய பதிவுகளுக்கு Old entry ON; வழக்கமான இன்றைய வசூலுக்கு Settings-ல் OFF செய்யலாம். விடுமுறை நாளை Book holidays-ல் தேர்வு செய்யலாம். வசூல் முடிந்த பிறகு மட்டும் Collection finished உறுதிப்படுத்துங்கள்.

10. கடன் முடிந்ததும், தொடர்ச்சி புத்தகமும்

கடன் முழுவதும் முடிந்த பின் வரும் வாரங்களில் — தெரியும்; அது புதிய வசூல் அல்ல. பழைய தொகையைத் திருத்தினால் மீதி மீண்டும் கணக்கிடப்படும். Settings → Continue in a fresh volume மூலம் அதே கிழமைக்குப் புதிய புத்தகம் தொடங்கலாம். பழைய புத்தகம் அழியாது; பாக்கி உள்ள கடன்கள் அசல் தேதி, பழைய பதிவுகளுடன் தொடரும். பழைய பக்கத்தை அதன் தேதியிலோ archive link-லோ திறக்கலாம்.

11. மற்ற வசதிகள்

இன்று வசூல் கிழமைக்கு பொருந்தும் செயலில் உள்ள புத்தகம் இருந்தால் திறக்கும்; இல்லையெனில் புத்தகப் பட்டியல் வரும். Back அழுத்தினால் முந்தைய பகுதிக்குச் செல்லும்; வெளியேற முன் கேட்கும். Screenshot அனுமதி Settings-ல் உள்ளது; படத்தில் பெயர், தொகை தெரியும். Login பக்கத்தில் Check for updates தொட்டால் மட்டும் இணையத்தில் புதிய பதிப்பைப் பார்க்கும். App தானாக update நிறுவாது. சாதாரண பதிவுக்கு இணையம் தேவையில்லை. Update செய்ய uninstall அல்லது data clear செய்ய வேண்டாம்; அதற்கு முன் வெளிப்புற backup வைத்திருங்கள்.

கூடுதல் விவரங்கள்

தமிழ் தேதி Settings-ல் விருப்பமாக இயக்கலாம். 15-01-2026 முதல் 31-12-2026 வரையிலான தேதிகளுக்கு மட்டுமே தமிழ் தேதி காட்டப்படும்; மற்ற தேதிகளில் வழக்கமான தேதி மட்டும் தெரியும். புத்தகத்தில் உள்ள பெயர், பண விவரங்கள் தனிப்பட்டவை; screenshot அல்லது backup-ஐ கவனமாகப் பகிருங்கள்.
