# Tamil Podcast Player (கதை சொல்லி)

**Current stable release:** 1.4 / code 6

Package `com.universalrp.podcast`. Android 8.0 / API 26 or later.

## Features

- **Real offline downloads:** Download beside an episode; use Downloads for progress, stored sizes, Wi-Fi-only settings, retry, cancellation and deletion. Play offline requires a complete local file and never falls back to streaming.
- **Eleven sources, six categories:** News/world, history, literature, science/space, learning and children’s stories, with category filters, show search and episode search. A curated catalogue, not every Tamil podcast on the web.
- **Persistent player:** Play/pause, seek, elapsed time, duration, fifteen-second skips and saved-position resume, with media-session controls and audio-focus handling.
- **Browser updates:** No package-install permission or update APK provider. About opens official release pages in the browser; the app does not download or install APK updates.

## Permissions and privacy

No account, ads, app analytics, microphone, contacts or shared-storage permission. Publisher feeds, audio and artwork use the network. Downloads use app-specific storage and are excluded from standard Android backups; uninstalling removes them. Notifications are requested on first playback on Android 13+, but denial does not block listening. Podcast publishers may receive network request metadata.
